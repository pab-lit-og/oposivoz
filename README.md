# OposiVoz

Estudia la oposición con la voz: te lee la pregunta y las cuatro opciones, contestas en voz alta y lo que fallas vuelve hasta que lo sabes.

**Usar:** https://pab-lit-og.github.io/oposivoz/

- Beta gratuita, sin cuentas, sin cookies y sin analítica: el progreso se queda en tu navegador.
- Material de estudio no oficial; cada pregunta se contrasta con el texto consolidado del BOE.
- ¿Un error en una pregunta? Abre una incidencia en este repositorio.
